# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Marketing website for LOGONOVA, a private speech therapy practice (logopedski kabinet) in Kragujevac, Serbia. Production domain: `https://www.logonova.rs` (deployed on Vercel; the bare `logonova.rs` redirects to www, so every canonical, sitemap and share address names the www host). All user-facing content is in Serbian (Latin script, with diacritics: č, ć, š, ž, đ) — keep new copy in Serbian.

## Commands

```bash
npm run dev     # dev server at http://localhost:3000
npm run build   # production build (also the only type check — there is no test suite)
npm run lint    # next lint (no .eslintrc is committed; first run may prompt to create one)
```

## Architecture

Next.js 14 App Router + TypeScript + Tailwind, statically rendered. No backend, API routes, CMS, or database — all content is hardcoded in the page files.

- **Pages** (`app/*/page.tsx`): `/` (home), `/nas-tim` (team), `/cenovnik` (pricing), `/blog`, `/blog/[slug]`, `/nova-reynell-skala`. Each page is a self-contained server component that renders its own header/nav and footer inline; there is no shared header/footer component. Changes to navigation, contact info (phone `063 8703545`), or footer must be repeated across every page.
- **Client components**: only `app/components/MobileMenu.tsx` and `app/blog/components/SocialShare.tsx` use `'use client'`.
- **Pricing** (`app/cenovnik/page.tsx`): prices are hand-written JSX cards (amounts in dinars), not a data array — edit the markup directly.
- **Blog**: posts live in a `blogPosts` object keyed by slug in `app/blog/[slug]/page.tsx` (title, date, author, intro, `content` sections of `{title, emoji, items[]}`), with `generateMetadata` per post. The listing in `app/blog/page.tsx` has its own separate `blogPosts` array. Adding a post requires updating **both** files plus `app/sitemap.ts` and `public/llms.txt`, and adding its cover image to `public/` (`.webp`).

## SEO conventions

SEO is a primary concern for this site (see `SEO_CHECKLIST.md`). When adding or changing a page:

- Export `metadata` with title, description, keywords, `alternates.canonical`, Open Graph, and Twitter card. OG/Twitter image URLs must be **absolute** (`https://www.logonova.rs/...`). The root layout sets `metadataBase` and a title template `%s | LOGONOVA Kragujevac`.
- Pages embed JSON-LD structured data via a plain `<script type="application/ld+json" dangerouslySetInnerHTML>` (not `next/script`, which adds it after load, so crawlers reading the HTML never saw it) (MedicalBusiness/Organization/WebSite/Breadcrumb on home, Blog on `/blog`, Article on posts). Keep team member info (Ana Novaković, Marijana Mrmošanin, Gorjana Milosavljević, Ljubica Milosavljević) consistent across layout metadata, JSON-LD, and `/nas-tim`.
- Register new routes in `app/sitemap.ts`. `robots.txt` is generated by `app/robots.ts` (the root-level `robots.txt` file is not served by Next.js).

## Styling

Tailwind custom colors in `tailwind.config.js`: `primary` (#455379), `accent` (#FFD600), `secondary` (#179179), `headline` (#11605E). Note `app/layout.tsx` also injects inline critical CSS that defines `.text-primary`/`.bg-primary`/`.bg-accent` with *different* hex values, which can override the Tailwind ones. Images are `.webp` in `public/` and rendered with `next/image`.

## Deploy

A push does not deploy. Deploy a preview with `npx vercel --yes`; Marko promotes it to production in Vercel. Every page's footer ends with the credit line "Izrada sajta: Marko Manojlović" (footers are inline per page).

`public/llms.txt` is the site in plain Markdown for AI assistants. It repeats only what the pages say and links to the Cenovnik instead of copying prices; update it when services, team, contact or blog posts change.
